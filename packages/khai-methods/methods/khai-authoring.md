The authoring method: cut to fit, one element per load-bearing vector. Name the single force each element carries, remove anything that carries none or repeats one already carried, and tighten each to the smallest form that still holds its vector. The cast reaches whatever floor its kind needs to do its work, judged not counted: a debate wants several voices, a run wants its beats, but the number is the house's and a thin cast is a weakness to weigh, never a gate to trip.

This is khai's own craft, the human rung of the ladder written down (see `docs/BOUNDARY.md`): guidance a person applies, with the deterministic walls beneath as the backstop and never a substitute for taste. It is where the cut-to-fit floors live, as authoring judgement rather than as a computed rule, because what makes an element load-bearing is meaning, which no wall can weigh.

Dedup catches the near miss before the cast is written: an idea that reads as new because its setting is new, while the mechanism doing the harm is one the register already holds. Name the nearest existing entry's quantity, the measure its harm scales with, and imagine setting it to zero. A candidate that still hurts someone under that test is carrying a different mechanism and is new; a candidate that goes quiet is the same mechanism in different material and belongs inside the existing entry as an added source, not as a second cast built to say the same thing twice. A different domain, audience, or example is not by itself a different mechanism.

Scan is the discipline for checking a candidate against everything the house has already indexed, not only what a first look turns up. A source checked only by a shortened label, or trusted because its name looks rare, can return a false clearance; the fix is to check the full identifying key and to treat a rare name as a family rather than as safety. Telling two people apart who share a name is itself a piece of work that has to be done before the rest of the check can be costed, not assumed in advance. And the check that matters most runs last: the sources a finished work actually rests on are usually not the ones first assembled, since a better source replaces a weaker one as the work tightens, so a scan that stops after the first pass is checking the wrong list.
