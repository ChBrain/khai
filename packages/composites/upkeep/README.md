# Upkeep

Upkeep as composite: what a shared thing costs the people who keep it -- a pool that anybody can draw from and nobody can easily be kept out of (the pool), a contribution set by what each persona expects the others to do rather than by what the rule says (the read), and an enforcement somebody pays for out of their own pocket with nothing coming back (the sword) -- wired over the commons, trust, and altruistic-punishment engines.

This engine is defined by its [manifest](package.json), which the canon renders as the WIRES card. The manifest is the single source of truth; this README is generated, not edited by hand.
