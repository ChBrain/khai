# Process: Clime, the Run

## Taxonomy

[Clime](process_clime.md), the only evidence anyone actually holds, and where the two are seen for one thing.

## Owner

- Project: khai
- Engine: clime

## Initiated by

It has happened again, and this is the third time.
The Run starts wherever a stretch of days has begun to look like something -- the summer that came early once too often, the harvest failed three years running, the winter that did not arrive, the [season](@chbrain/khai-engine-weather/process_season.md) that no longer sits where the [seasonality](@chbrain/khai-engine-climate/process_seasonality.md) says it should -- and it is where a [shift](@chbrain/khai-engine-climate/process_shift.md) in the regime, if there is one, is doing the only showing it will ever do while it still matters.
It is the face of the composite that everybody in fact reasons from, and the only one neither engine owns.

## Direction

Toward a conclusion the evidence cannot carry and the situation demands.
The Run reads the stretch that is too long to be dismissed and too short to be decided -- long enough that shrugging it off has started to feel like a refusal, short enough that any statistician can say honestly that it is consistent with the old regime -- and reads the position that puts a place in: obliged to act on the terms, able to observe only the days, and holding a sequence that will not resolve into either.
It moves the place toward a decision it will have to make before it can be right.

## Lever

The exactness of the only available evidence against its structural inability to settle the question.
The carrying force is that the run is not nothing: it is the one place a moving regime becomes visible from inside, and a place that waits for certainty has waited past the point where knowing would have helped, because the adaptation it would have to change takes longer to change than the shift takes to arrive; the resistance is that every single day in the run is individually explicable, so the sequence can be honestly denied one member at a time by anyone who wants to, and the people denying it are not being stupid -- each of their explanations is correct.
The Run rides the composite's keystone knife-edge: the only thing anyone can feel is a sample, and a sample is not evidence of the odds it came from, though the odds are made of nothing else.

## Echo

Everything known and nothing settled.
It shows the two engines complete -- one that falls and can be felt, one that governs and cannot -- and carries beneath it the composite's keystone: the day that most feels like proof is the least informative, the record that would be proof is unavailable to experience, and the run in between is the only thing anyone has and is exactly the thing that cannot decide.
This is why a shift is argued about while it is happening and obvious only afterwards, and why the argument is not a failure of anybody's intelligence: the question was asked of the one instrument that cannot answer it.
The Run is the note the whole composite closes on: what a place is set in is legible in its record, and in nothing anyone in it will live long enough to see.
The Run is dated from the second time it happened, when it first became possible to be wrong about it.
