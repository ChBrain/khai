# Process: Code, Reading

## Taxonomy

[Condemnation](process_condemnation.md), the bridge where one act is coded now one way, now another.

## Owner

- Project: khai
- Engine: condemnation

## Initiated by

A single act that more than one code could claim.
The atoms each answer a code as given -- but which code a wrong belongs to is not given, it is read.
The same act -- a flag burned, a food eaten, a body shown, a rule broken -- can be coded as a harm (autonomy, drawing [anger](@chbrain/khai-engine-anger/process_anger.md)), a betrayal of the order (community, drawing [contempt](@chbrain/khai-engine-contempt/process_contempt.md)), or a defilement (divinity, drawing [disgust](@chbrain/khai-engine-disgust/process_sociomoral.md)), and different personas, cultures, and moral palates read it differently.

## Direction

From the act to a code, by the reader's lights -- and between codes as it is re-read.
Shweder's three ethics and Haidt's Moral Foundations name the split: some readers weight autonomy (care, fairness) and see only harm, or none; others weight community (loyalty, authority) or divinity (sanctity) and see betrayal or defilement where the first saw nothing.
Moralization runs here too -- a mere preference pulled into a moral code (Rozin's account of how a health choice or a habit becomes a purity matter), the act re-coded from neutral to condemnable.

## Lever

What the reading exposes -- that the condemnation was never in the act but in the code the reader brought to it.
The composite spends the illusion of a single moral meaning: change the code, and contempt, anger, or disgust fires instead, or nothing does.
This is the axis on which moral conflict turns -- not disagreement about the facts, but about which code the facts fall under.

## Echo

The act is condemned, acquitted, or fought over, by the codes the readers hold.
A production that stages the reading, rather than fixing one code, shows why the same scene can divide a room: one persona's disgust at a defilement is another's shrug at a harmless act, one's contempt at a betrayal is another's respect for a rule well broken, one's anger at a harm is another's blindness to it.
The reasoned adjudication of which reading is right is the moral-judgment engine's; this bridge owns only the fact that the code is a reading, and that the condemnation follows it.
