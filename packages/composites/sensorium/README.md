# Sensorium

Sensorium as composite: the place as the body meets it apart from the eye -- the constant olfactory, acoustic, and haptic field it sits in (ground), the smell, sound, or pressure that rises from that field and marks the place (figure), and the sense withheld (absence) -- and the drama is that a place is felt hardest where a sense has been taken away.

This engine is defined by its [manifest](package.json), which the canon renders as the WIRES card. The manifest is the single source of truth; this README is generated, not edited by hand.
