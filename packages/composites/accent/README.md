# Accent

Accent as composite: what it costs a persona to be understood in a room, and who the room charges for it -- the width at which each channel holds the tongue, from a language gripped as a foreign object up to one that needs no grip (the width), the specialist code layered on top of it, which binds insiders and gates outsiders at once (the code), and the discount a listener applies for their own effort, since the difficulty is felt in the hearer and charged to the speaker (the discount) -- wired over the language and register engines.
