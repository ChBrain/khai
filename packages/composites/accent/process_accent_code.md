# Process: Accent, the Code

## Taxonomy

[Accent](process_accent.md), the specialist code layered on the tongue, and the second gate.

## Owner

- Project: khai
- Engine: accent

## Initiated by

The room is not speaking the language, it is speaking a version of it that belongs to somebody.
The Code starts wherever [register](@chbrain/khai-engine-register/position_register.md) is running -- as [shorthand](@chbrain/khai-engine-register/position_shorthand.md) that lets insiders be fast and exact, as a [badge](@chbrain/khai-engine-register/position_badge.md) that shows who is of the community and reads others' belonging from how they use it, as [closure](@chbrain/khai-engine-register/position_closure.md) that shuts the lay listener out, or as [translation](@chbrain/khai-engine-register/position_translation.md) that drops the code to carry the meaning across.
It is the face of the composite where a native speaker can be as far outside as anybody.

## Direction

Toward a second admission test, taken at the same time as the first.
The Code reads the gate as independent: the register sits on top of the base tongue and is acquired separately, so it sorts a room along a different line -- and a persona at native width in the language can be entirely outside the code, while a persona at borrowed width may command the code precisely because it is what they were taught.
It moves the boundary of the room without moving anybody's competence.

## Lever

The precision a shared code buys against what it costs whoever does not have it.
The carrying force is that the code is doing real work and was not built to exclude: shorthand exists because insiders need to be fast and exact, and a room that dropped it would spend the evening on preliminaries -- so the closure is usually a side effect of an efficiency rather than a wall anybody built; the resistance is that the same feature does both jobs at once and cannot be separated into a helpful half and a harmful one, since the compression that makes it fast is the compression that makes it opaque, and the only remedy, translation, is a cost somebody has to volunteer to pay.
The Code spends the outsider's standing to buy the insiders' speed.

## Echo

A room going quickly, past somebody who had something to add.
It is the bridge that doubles the composite's problem and keeps it from being a story about foreigners: the two gates are independent, and a persona can be stopped at either.
What it hands upward is a second source of difficulty in the room, indistinguishable from the first once it reaches a listener -- because what a listener registers is not which gate is in the way, only that this is hard.
The Code is dated from whenever the community last settled its terms, and it does not announce them.
