# Borderline

Borderline personality organisation as composite: an emotional vulnerability that will not settle (regulation), an interpersonal hypersensitivity that reads availability moment to moment (attachment), a self that reorganises around whoever is present (identity, self-esteem), and a behavioural dyscontrol that regulates affect by other means (self-control) -- across its emotional-vulnerability, interpersonal-hypersensitivity, identity-diffusion, and dyscontrol movements (Linehan; Gunderson; Kernberg; Zanarini).
