# Vigil

Vigil as composite: what a persona does to a bond once a third party is in the room -- the threshold at which a rival starts to count, set by how the base has answered before rather than by the rival (the threshold), the watch mounted over the bond in vigilance, confrontation, and mate-guarding (the guard), and the reassurance the guarding is searching for, which the searching is the one thing that cannot produce (the proof) -- wired over the jealousy, attachment, and trust engines.

This engine is defined by its [manifest](package.json), which the canon renders as the WIRES card. The manifest is the single source of truth; this README is generated, not edited by hand.
