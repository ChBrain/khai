# Anomaly

Anomaly as composite: what a persona does with a thing that will not sort -- the scheme of kinds already in place, which sharpens its own boundaries as it is used (the scheme), the instance that falls between two kinds or into both, so the sorting returns no answer and will not stop trying (the misfit), and the charged rejection that arrives instead of a verdict and presents itself as news about the thing (the recoil) -- wired over the categorization, uncanny, and disgust engines.

This engine is defined by its [manifest](package.json), which the canon renders as the WIRES card. The manifest is the single source of truth; this README is generated, not edited by hand.
