# Forgoing

Forgoing as composite: what it costs to ask for help that only somebody marked would need. It is not a third mechanism but a wiring of two -- the stigma engine supplies the discrediting attribute and the discounting it draws, and the asking engine supplies the request for discretionary help, its reluctance, and the misestimate that runs one way. This composite adds no third engine; it reads the one thing the two make together, which is a request whose price is paid in identity rather than in imposition. Three bridges: the Price, where the request is itself the disclosure and the service is defined by who it is for, so a chance is being weighed against a permanence; the Avoidance, where the persona declines the classification rather than the help, which is why better provision does not reach the decision; and the Undercount, the twist -- everybody who declines stays out of the visible population, so the category is described by the cases that could not be concealed, and the forgoing is what keeps the mark worth avoiding.

This engine is defined by its [manifest](package.json), which the canon renders as the WIRES card. The manifest is the single source of truth; this README is generated, not edited by hand.
