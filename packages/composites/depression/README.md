# Depression

Depression as composite: the synergistic trap of a major depressive episode where anhedonia strips away restorative rewards, fatigue and psychomotor shutdown (melancholia) remove the energy to act, learned helplessness provides the cognitive evidence that action is futile, and worthlessness turns the resulting passivity into a permanent moral judgment.
