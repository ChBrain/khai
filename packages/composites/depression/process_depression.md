# Process: Depression

## Taxonomy

Depression. The synergistic trap of a major depressive episode. It is not a list of symptoms, but a self-sealing architecture where affective, cognitive, and somatic failures lock each other in.

## Owner

- Project: khai
- Engine: depression

## Initiated by

An initial trigger (a loss, a failure, chronic stress, or sometimes no identifiable event) that sets the atomic engines running simultaneously.

## Direction

Inward and circular. The failures feed each other: the [sadness](@chbrain/khai-engine-sadness/process_despair.md) deepens the [rumination](@chbrain/khai-engine-rumination/process_brooding.md), which focuses attention entirely on the [fatigue](@chbrain/khai-engine-body/process_fatigue.md) and [worthlessness](position_worthlessness.md), which neutralizes any attempt to act, which reinforces the [anhedonia](@chbrain/khai-engine-anhedonia/process_anhedonia.md).

## Lever

The trap. The engine's twist is that the state actively defends itself against resolution. The worse it gets, the more it disables the very mechanisms required to recover from it. The persona cannot simply "decide" to get better, because the cognitive tools for decision-making and the motivational drives for action are the exact components that are broken.

## Echo

A profound, inescapable heaviness. The persona is left trapped in a closed loop, where every attempt to escape only provides more evidence that escape is impossible.
