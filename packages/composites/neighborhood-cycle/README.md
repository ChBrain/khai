# Neighborhood-cycle

Neighborhood-cycle as composite: the whole arc a built place turns through -- decline, capital re-entry, and reclamation -- read as a wiring of the dereliction, gentrification, and reclamation engines over the decay they act upon, and the drama lives in whom the return serves: the community kept (stewardship), the capital served and the community displaced (turnover), or no return at all (attrition).

This engine is defined by its [manifest](package.json), which the canon renders as the WIRES card. The manifest is the single source of truth; this README is generated, not edited by hand.
