# Grapevine

Grapevine as composite: the informal communication network of a community read as one thing -- the unofficial channel through which evaluative talk about persons (gossip) and unverified news about events (rumor) both travel, converting into each other and gating each other's belief -- across the channel, blame, and credence seams over gossip and rumor, and the drama lives in the network carrying both at once, an event's account becoming a person's verdict and a reputation deciding what news will stick.
