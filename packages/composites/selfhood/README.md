# Selfhood

Selfhood as composite: the self as an object to itself -- measured against the guides it falls short of and the futures it might become (self-discrepancy, possible-selves), repaired elsewhere when threatened (self-affirmation), and anchored by feedback that matches how it already sees itself (self-verification) -- across the measure, the repair, and the anchor, and the drama is that a self needs to be known more than it needs to be thought well of.
