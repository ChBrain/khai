# Peopling

Peopling as composite: a place read by the presence in it -- the crossing done because it must be (the errand), the return kept on a rhythm (the round), and the staying done for no reason at all (the loitering) -- wired over the legibility, social-time, and street-life engines, and closing on the discovery that the only presence which reports on a place is the presence the place did not compel.

This engine is defined by its [manifest](package.json), which the canon renders as the WIRES card. The manifest is the single source of truth; this README is generated, not edited by hand.
