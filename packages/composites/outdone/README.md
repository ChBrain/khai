# Outdone

The responses to upward comparison as composite: one reckoning with another's superior standing, split by how the persona meets it -- warmly, with the pull to rise, or with the wish to pull down -- into admiration, benign envy, and malicious envy (van de Ven), and the drama lives where the responses tip into one another, where warmth sours to envy and benign envy hardens to malicious, and where one comparison is met three ways by the appraisals that sort it.
