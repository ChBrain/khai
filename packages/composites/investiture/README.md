# Investiture

Investiture as composite: how an object comes to carry an identity that is not in it -- taken into a single self so that losing it makes the self smaller (extended-self), withheld from exchange and passed down a line whose claim it makes visible (heirloom), or set apart by an assembled collective as the thing its we is lodged in (totem) -- across the held, the handed, and the hallowed, and the drama is that in every case the worth is not a property of the object, which is why no identical thing can replace it and why breaking it is felt as an injury to a person, a line, or a people.
