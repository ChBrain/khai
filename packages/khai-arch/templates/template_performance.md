# Performance: [title]

## Taxonomy

The group directly above: the production this evening belongs to. Name it; link the play it ran. Not this one's name (the H1) or its origin (Owner).

## Owner

- Project: [project]

## Lodged

Where the written performance lives: the link to the full captured script at its home in the result layer, which owns it. It must resolve, or this is not yet a performance - the ticket travels, the archive stays put. If the only copy is here, nothing was lodged and this is a script, not a loan.

## Occasion

The evening itself: which play was run, the key that was called, the Conditions the Human provided, the date, and the venue it played. Enough that a reader knows which of many runs this was, since the same play keyed otherwise is a different production. If two evenings cannot be told apart from this chapter, it is not filled yet.

## Aftermath

What the run closed, verdict shaped the way a plan's targets are: what was settled, what failed, what was left open when the Collaboration rested. The outcome a later production can stand on without reading the whole evening. If it retells the evening rather than resolving it, it belongs in the lodged script.

## Note

What was sent home: the word to the lenders whose members the run exercised, and to the production that comes next - what the evening taught about the cast, the key, or the shelf it was borrowed from. The return leg of the tour, written down. If nothing is owed back, say so; silence reads as an unwritten chapter.
