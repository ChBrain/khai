# Vouching

Vouching as process: standing lent to somebody else's claim, read on who agreed to give it rather than on what it said -- not the request for discretionary help, which is asking's, and not the second judgement offered on a decision, which is advice's -- across four movements: the request (a short list that is a network property presented as a personal one, an unrefusable ask that converts a reservation into a letter, and a second choice read as a substitution whatever it was), the writing (a positive floor that protects the candidate by disabling the instrument, a code that restores the signal and carries somebody else's assumptions with it, and a length that is the only uncompellable part and is mostly noise), the stake (borrowed standing that values the candidate at the referee's rate, collateral that is real, uncollected, and never itemised, and a repayment owed to somebody who is not collecting), and the reading (a discounted text taken seriously by exactly one of the three parties, a weighed source that assesses the referee and scores the candidate, and an absent letter that is the only signal available and cannot be interpreted) -- with the twist that nothing in a reference is informative except the fact that somebody agreed to give one.

This engine is defined by its [manifest](package.json), which the canon renders as the WIRES card. The manifest is the single source of truth; this README is generated, not edited by hand.
