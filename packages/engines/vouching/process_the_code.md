# Process: The Code

## Taxonomy

[The Writing](process_writing_vouching.md)

## Owner

- Project: khai
- Engine: vouching

## Initiated by

The referee writes in praise and expects to be read for omission.
And the reader reads for it.

## Direction

Toward a language in which the choice of compliment is the message.
Diligent, conscientious, hardworking, a pleasure to supervise: all warm, all doing the work of a reservation, and all readable as such by anybody in the trade. Brilliant, original, the best in a decade: also warm, and a different message entirely.
Studies of large sets of letters find these registers distributed unevenly across candidates in ways that track the candidate's group rather than their record -- more grindstone praise here, more standout praise there, more doubt raisers and more mention of personal circumstances in one set than the other.

## Lever

The precision the code achieves against what it smuggles in.
The carrying force is that the code works and is not a deception: readers and writers share it, it lets a referee be honest without being cruel, it preserves the protective floor while restoring some signal, and a system with no such register would force people to be either useless or brutal; the resistance is that the register is applied unconsciously, so a difference in wording that everybody can read is produced by nobody deliberately, and it lands on the candidate as a judgement that was never made about them.
The Code restores the signal and carries somebody else's assumptions with it.

## Echo

A warm sentence doing cold work.
It shows how information survives a channel that forbids it.
The Code is dated to the drafting and is not visible to the person described.
