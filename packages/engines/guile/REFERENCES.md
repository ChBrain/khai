# Guile: Reference

## Line of Work

Guile as **piece**: the object designed to mislead the user for the maker's benefit
-- the dark pattern, where the lie is the intent and not a defect, deceiving the user
into acting against their own interest. The domain does not model an honest design
defect, which usability owns (a false cue the maker would fix); nor a social-order
program enforced on conduct, which agency owns (concealed politics, not a trick
against the user's interest); nor a persona's own deceiving of another, which the
deception engine owns (interpersonal false belief, read on a persona). It models the
object built to deceive: the piece-pole of deception, maker-absent and scaled to
every user who meets it.

The spine is the dark-patterns literature -- Brignull's naming of the deceptive
interface, Gray's taxonomy of its kinds, Mathur's measurement of it at scale. The
engine takes the object's designed deceit five ways, after Gray: what it hides
(sneaking), the wanted path it obstructs (obstruction), the request it repeats
(nagging), the unwanted act it forces (forcing), and the choice it misrepresents
(misdirection) -- so a piece can declare not only that it deceives but by which
trick.

## Restrictions

What the engine refuses to model, and to whom it delegates.

- **The honest design defect (usability)**: The usability engine owns how the form
  communicates its use, and its lie is a _defect_ -- a false cue the maker would fix,
  the user's failure and not the maker's aim. Guile's lie is the _intent_ -- engineered
  to work for the maker against the user. The false "pull" on a push door is usability;
  the pre-checked add-on box is guile. The two share the surface (both read on Apparent)
  and split on intent.
- **The social-order program (agency)**: The agency engine owns the object enforcing a
  program on conduct, concealed and borne. Both hide -- but agency conceals a
  _social-order program_ (the anti-sleep bench, a policy on whom), while guile deceives
  the user into a _transaction against their own interest_ (the hidden charge, the steered
  click). Agency governs conduct; guile takes a gain.
- **A persona's own deception (the deception engine, on a persona)**: The deception
  engine models interpersonal false belief -- a persona creating a false belief in
  another's mind. Guile is the _object_ designed to deceive: the piece-pole of the same
  science, maker-absent and scaled. Same word, different science, different type.
- **The behavioral pole (captology)**: Guile _deceives_ -- it creates a false belief, a
  trick sprung on the user; captology _conditions_ -- an engineered reward loop that
  forms a habit over time. A dark pattern catches you; a hook trains you. They co-occur
  (a nag that hardens into a habit) but the mechanisms differ.
- **The facet is not engine content**: The engine declares the five facets exist; which
  one a given piece turns on lives on the piece, linked under its Apparent chapter. The
  engine refuses to fix a piece's trick for it.

  the click. Anchored by Brignull (misdirection) and Gray (interface interference).
