# Process: The Hedging

## Taxonomy

[The Reluctance](process_reluctance_asking.md)

## Owner

- Project: khai
- Engine: asking

## Initiated by

The request, if it is made at all, arrives wrapped.
I don't suppose, no worries if not, only if you have a minute, this is probably a stupid question.

## Direction

Toward a request built so that a refusal costs nobody anything.
The hedging is not weakness. It is working machinery: it hands the other person a prepared exit, which is what makes the request askable, and it protects the relationship against the version in which a refusal would be a rejection.
It is also a discount applied to the request before anybody has looked at it.

## Lever

The kindness of the escape hatch against the size of the discount.
The carrying force is that the hedge does necessary work: a request with no exit is an instruction, the helper needs somewhere to stand if the answer is no, and the persona who asks flatly for large things is usually the one nobody wants to see coming; the resistance is that the wrapping is heard as information about the request's importance, so a persona hedging a serious need can be declined by somebody who would have moved a great deal had they understood.
The Hedging protects both parties and misreports the size.

## Echo

A request that arrives smaller than it is.
It shows the reluctance surviving into the act itself.
The Hedging is dated at the moment of asking and is applied automatically.
