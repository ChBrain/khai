# Self-discrepancy

Self-discrepancy as process: the gap a persona feels between its actual self and a self-guide -- the ideal self it hopes to be, whose shortfall brings dejection (sadness, disappointment), and the ought self it feels bound to be, whose shortfall brings agitation (anxiety, guilt) -- across the ideal and ought discrepancies, tuned by a standing discrepant profile (Higgins).
