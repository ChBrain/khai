# Process: Simulation

## Taxonomy

[Imagination](process_imagination.md), the constructive mode -- a novel scenario assembled from parts and run forward.

## Owner

- Project: khai
- Engine: imagination

## Initiated by

A persona builds a whole scene that never happened and sets it going.
Simulation starts wherever a persona assembles a novel scenario from remembered and invented pieces and runs it -- the meeting rehearsed before it happens, the argument played out three ways, the escape imagined step by step, the life not taken pictured whole -- the mind's model of an event, constructed and set in motion to see how it would go.
It is the constructive, combinatorial mode: imagination as the flexible recombination of stored elements into a coherent episode that was never experienced, the same constructive machinery Schacter and Addis found the brain using to remember the past and to imagine the future alike.

## Direction

Forward through a built scenario, watching it unfold.
Simulation composes an episode and plays it -- the persona drawing details from memory and filling the rest by invention, holding the scene coherent, and then letting it run so that consequences emerge the persona did not stipulate: the imagined conversation that turns, the rehearsed plan that hits a snag, the alternate life that sours.
It moves the mind from parts to a working model: not a single image or a bare premise but an assembled, temporally-extended scenario, run so its outcome can be read -- the mental rehearsal that informs a choice, the pre-experience that lets a persona feel a path before taking it.

## Lever

The coherence of the built scenario against the incoherence of arbitrary assembly.
The carrying force is the persona's power to recombine elements into an episode that hangs together and runs by something like real dynamics -- so the simulation's outcome is informative about the world; the resistance is the combinatorial looseness that makes the same power err: a scenario built too freely, run on wishful rather than real dynamics, yields a rehearsal that misleads -- the daydreamed triumph, the catastrophized disaster, the plan that works only in the head.
Build the scenario coherent and run it honestly and the simulation pre-experiences a real possibility; build it to flatter or to dread and it rehearses a fantasy, and the mind mistakes its own construction for a forecast.

## Echo

The imagining read as its run scenario.
Simulation leaves the persona holding a built, played-out episode -- the rehearsed meeting, the alternate life, the imagined outcome -- and hands that scenario to planning, decision, and the feeling of a path not yet taken.
It is the constructive face of imagination and its most consequential: the mode that lets a persona try a future before living it, inhabit a life it did not lead, and pre-feel the results of a choice -- the same faculty that, run on wishes or fears, produces the fantasy that consoles and the dread that paralyzes.
Simulation is read from the running, the persona known by the scenarios it builds and sets going in the mind.
