# Coping

Coping as process: the effortful, appraisal-driven repertoire a persona deploys against a stressor -- sizing up what is at stake and what can be done, acting on the problem, or escaping it -- across the appraisal, problem-focused, and avoidant forms, with the management of the emotional response itself handed to the regulation engine (Lazarus & Folkman; Carver).

This engine is defined by its [manifest](package.json), which the canon renders as the WIRES card. The manifest is the single source of truth; this README is generated, not edited by hand.
