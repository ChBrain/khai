# Process: The Refusal

## Taxonomy

[The Hold](process_hold_germination.md)

## Owner

- Project: khai
- Engine: germination

## Initiated by

The seed is wet, warm, and does not grow.
Everything a gardener would call right is present.

## Direction

Toward an enforced block rather than an absence of readiness.
The mechanism is a balance between substances that hold germination down and substances that release it, and it is maintained. A seed in this state is spending energy on not doing something, and the state can be lifted chemically in a laboratory, at which point the seed germinates within hours.
So the correct description is not that the seed cannot; it is that the seed is arranged so that it will not.

## Lever

The value of an enforced refusal against the energy and the time it consumes.
The carrying force is that a maintained block is far more useful than a passive one: it can be tuned, released by a specific signal, and set at different strengths in different seeds from the same plant, which is a level of control that mere inability could never provide; the resistance is that maintenance costs, so the seed is spending part of a finite store on staying shut, and a block set too strong for its environment will still be holding when the seed is no longer alive to release it.
The Refusal is something the seed is doing, not something being done to it.

## Echo

A capability held down on purpose.
It shows why the engine treats dormancy as the seed's principal activity.
The Refusal is dated to the seed's making and is relaxed only by the right signal.
