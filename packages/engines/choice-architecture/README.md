# Choice-architecture

Choice architecture as piece: the arrangement of the options an object offers -- what stands if the user does nothing (preset), what each path costs to take (sludge), where the options sit and which is met first (ordering), and how many are offered at all (assortment) -- an arrangement the maker cannot decline to make, since every setting of it is a setting.

This engine is defined by its [manifest](package.json), which the canon renders as the WIRES card. The manifest is the single source of truth; this README is generated, not edited by hand.
