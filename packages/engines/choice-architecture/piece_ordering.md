# Piece: Ordering

## Taxonomy

[Choice architecture](piece_choice_architecture.md), the facet this is a part of. Ordering models where the options sit -- which is met first, which is at eye level, which is on the second page, which sit grouped with what. The position-effect literature: Bar-Hillel on choice from simultaneous displays and on menu position, Chandon and colleagues on shelf position and facings. It is distinct from usability, which asks whether the form communicates its own use -- an ordering can be perfectly legible and still tilt the result -- and from guile's misdirection, where the layout is rigged to steer the eye against the user and the intent is the trick. The point of this facet is the ordinary case: a list has an order whether or not anybody chose it, alphabetical is an order, and whatever the database returned is an order too.

## Place

On the list, the menu, the plan table, the shelf, the search result, the page of results, and the sequence of screens -- anywhere a set of options has to be laid out, which is anywhere a set of options exists.

## Load Bearing

What an ordering holds up is the distribution across the options: what fraction took the first, what fraction reached the last, what the top result's share is against the one below it. Reorder the same set and the shares move without a single option changing -- same prices, same features, same words, different outcome. It bears the fact that a set of options is never actually met as a set. It is met one item after another, under attention that runs out, and by the time the later ones arrive most of the choosing has already been done.

## Apparent

It shows as neutral, and this is the facet where that reads most convincingly. A list looks like the options themselves rather than an arrangement of them; the order presents as incidental -- a consequence of the alphabet, of the date, of whatever the system happened to return -- precisely where it is load-bearing. What is apparent is a set; what is borne is a sequence.

## Yearbook

The record of an ordering is what got picked from each position: the click share of the first result, the item at eye level, the plan in the middle column, the options on the page nobody scrolled to. Its dates are the reshuffles -- the day the same list came back in a different order and the shares followed the positions rather than the items.
