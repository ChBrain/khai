# Ostracism

Ostracism as process: being ignored and excluded, and the staged response it triggers -- a reflexive pain and threat to belonging, control, self-esteem, and meaningful existence, then a reflective coping that fortifies the threatened needs, then the resignation of prolonged exclusion, across the reflexive, reflective, and resignation stages (Williams' temporal need-threat model).
