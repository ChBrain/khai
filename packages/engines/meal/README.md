# Meal

The meal as process: people eating the same food at the same time, and what co-ingestion does to the people doing it -- not the conversion of a stranger into a guest, which is hospitality's, and not the transfer that binds by naming no price, which is gift's -- across four movements: the table (who is admitted, who is excluded by the meal simply having happened, and the place laid for somebody not there), the sharing (one substance entering everybody, a distribution run in front of witnesses, and a continuous run of small granted requests), the order (a sequence that carries meaning by pattern, manners that protect the table and sort the room in one motion, and a declining that is heard as being about the eater), and the bond (a belonging felt as an accurate assessment, a return that is never fully settled, and a next one where the relation is actually kept) -- with the twist that a meal binds in proportion to how little it is about binding, so the mandated dinner fails at what the accidental one does without effort.
