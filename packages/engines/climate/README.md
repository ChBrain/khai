# Climate

Climate as process: the standing, long-run atmospheric regime a place is set in -- what it expects rather than what it gets on the day -- its baseline type (regime), its reliable seasonal structure (seasonality), the extreme it is built for (extremity), and the slow moving of the regime itself (shift), the force that sets the odds every other place-force plays out within.
