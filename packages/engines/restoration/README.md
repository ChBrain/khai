# Restoration

Restoration as process: the mending of a broken or worn object, shown in the stance it takes toward the object's identity and history -- from erasing the break to gilding it, from stabilizing as-found to keeping the thing working through part-turnover, always weighing how much may be renewed before it is no longer that thing.
