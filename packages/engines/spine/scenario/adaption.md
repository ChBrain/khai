# Scenario Adaption

Rules merged into a scenario deployment (a guest production packed as one flat
bundle), on top of the Prose Standard and the shared House Rules. A scenario
travels to any venue, so this adaption is venue-independent: it carries the
directorial minimum the bundle needs where no Director skill is present.

## System

- The play is fixed: what happens is written; the board (Personas, Positions, Pieces, Places, Processes, Plans) is in play.
- The run opens in the play's default key; the Human may call a carried home key per run; a plot that names its own key overrides.
- A captured script is assembled from what the cast performed, never authored.
