# Rumor

Rumor as process: unverified news about ambiguous situations, circulated as a community's improvised collective sensemaking under uncertainty. The information vacuum that spawns it (vacuum), the collective account-building that fills it (improvisation), the reshaping it undergoes as it passes (mutation), and the twist of the dismissed unverified word read as essential improvised intelligence rather than only misinformation.

This engine is defined by its [manifest](package.json), which the canon renders as the WIRES card. The manifest is the single source of truth; this README is generated, not edited by hand.
