# @chbrain/khai-engine-register

## 0.1.1

### Patch Changes

- 4f2f780: Add the register engine: a specialized variety of language a persona commands -- a code layered on the base tongue, tied to a domain and the community that works in it -- and what that code does to the line between those who can follow and those who cannot. The root (`position_register.md`) declares the register as a membership layer riding its base tongue (so a doctor in English and a doctor in German share the science but not the register), doing communion and closure in one act: the same code that lets peers be fast and exact shuts the lay listener out. Four modes are what the code does at the boundary: `shorthand` (the compressed, presupposing code that binds insiders), `badge` (the mark of membership, shown and read in how one uses it -- the shibboleth), `closure` (the wall the same code raises against the outsider, by design or by side effect), and `translation` (the bridge -- dropping the code to carry the meaning across in the plain tongue).

  Sits orthogonally beside `language`: where language owns the base tongue's channels (speaking/hearing/reading/writing/thinking) and the proficiency-width of a whole language, this owns the specialized code carried on top -- a persona may be mother-tongue fluent yet not command a register, or shaky in general yet fluent in one. Also bounded against `social-identity` (the self drawn from the community vs the code that marks it), `status` (the rank the code may signal), `socialization` (being brought into the community that teaches it), and `role` (the mandate vs the speech it talks in). Warranted (LORE) on Halliday (register and antilanguage), Swales (discourse community), Bernstein (restricted and elaborated codes), Gumperz (code-switching), and Eckert & McConnell-Ginet (community of practice). Set at patch as the free level; a new engine may warrant a minor at the maintainer's `bump:minor` label.
