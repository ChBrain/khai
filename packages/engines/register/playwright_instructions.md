# Instructions: Register

How a Playwright wires the register engine into a play. You wire by linking the play's own content to the engine's files; the engine files stay untouched, they are canon. The Roadie plumbs the engine's law into Instructions Knowledge on deploy. Authoring guidance, not runtime content, and it does not go on tour.

## Human

- The human defines the register terrain: which specialized code the persona commands, which community it belongs to, and who in the scene shares it and who does not -- the split that gives the code its work to do.

## Agent

- From the play's own content, a persona links the register mode the moment runs (shorthand, badge, closure, or translation) under its Projection. Let the mode shape what the persona's specialized speech does to the room -- who follows at speed, who is shut out, who is being placed, whether the persona drops the code to be understood. You link to the engine, you never edit it.

## Collaboration

- The base tongue the register rides -- the channels of speaking and hearing and the proficiency in the whole language -- is the language engine's; the register is orthogonal to it. The self a persona draws from the community is social-identity's; the rank the code may signal is status's; being brought into the community that teaches the code is socialization's; the role that speaks it is the role engine's. This engine supplies the code and its boundary work.

## Knowledge

- A register is a specialized variety of language layered on the base tongue, tied to a domain and community, that binds insiders and gates outsiders in one act; it rides its base tongue and cannot leave it. Shorthand is the compressed, presupposing code that lets insiders be fast and exact. Badge is the register as a mark of membership, shown and read in how one uses it. Closure is the wall the same code raises against the lay listener, by design or by side effect. Translation is dropping the code to carry the meaning across to the outsider in plain language.

## System

- Do let the register do communion and closure at once -- the code that speeds the insider is the code that shuts the outsider out.
- Do use the split in the room: the same line of shop-talk reads as ease to the peer, as a wall to the layman, as a test to the novice.
- Do let translation cost something -- the speed and the badge given up to be understood.
- Do delegate the base tongue and its channels to the language engine; this engine holds the code on top, not the language beneath. Do not edit the engine's files; wire only from the play's side.
