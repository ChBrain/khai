# Warning

Warning as process: a harm signalled before it arrives, to somebody who would have to act -- not the hazard and its assessment, which is risk's, and not the persona's response to a threat in the room, which is fear's -- across four movements: the issuing (a threshold that buys sensitivity with noise at a rate it does not choose, a confidence accurate on issue and binary on arrival, and a liability carried by one party and paid for by another), the receiving (milling that searches for a signal only produced once somebody stops searching, a normalcy read correct on almost every occasion and worthless on the ones that matter, and a personalising that decides the outcome in a second), the repetition (habituation that cannot tell the ninth false alarm from the tenth true one, muting that is defensible one at a time and indefensible in a list, and recalibration that is good reasoning arriving at a lethal answer), and the aftermath (an averted harm that is the engine's best outcome and weakest exhibit, a blame that corrects one error by amplifying the other, and a next warning heard at a volume set by events that had nothing to do with it) -- with the twist that a warning that works looks exactly like one that was wrong, so the only warnings that unambiguously earn credibility are the ones nobody acted on.

This engine is defined by its [manifest](package.json), which the canon renders as the WIRES card. The manifest is the single source of truth; this README is generated, not edited by hand.
