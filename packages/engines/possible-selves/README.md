# Possible-selves

Possible selves as position: the future-oriented self-representations a persona carries -- what it hopes to become, dreads becoming, realistically expects to become, and has given up becoming -- across the hoped, feared, expected, and lost standings, motivating most when a hope is balanced by its feared opposite and linked to a strategy (Markus & Nurius; Oyserman; King).

This engine is defined by its [manifest](package.json), which the canon renders as the WIRES card. The manifest is the single source of truth; this README is generated, not edited by hand.
