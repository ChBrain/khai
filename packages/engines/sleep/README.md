# Sleep

Sleep as process: what a persona must set down before the day's largest need will be met -- not the tiredness that pulls on attention until it is answered, which is the body engine's, but what answering it requires and what happens when it is not answered -- across four movements: the surrender (sleep as the deliberate suspension of vigilance, which requires a body willing to stop monitoring, so the persona with least reason to feel safe gets the worst sleep and is blamed for the deficits), the debt (a cumulative dose-dependent deficit running behind a subjective gauge that flattens after a few days, so the most impaired persona is the least able to report it and will sincerely insist they are fine), the effort (Espie's attention, intention, and effort -- each reasonable, together the documented mechanism of insomnia), and the schedule (a largely constitutional body clock against a non-negotiable social one, with night work as the case that never resolves) -- with the twist that sleep is the only thing a persona cannot obtain by trying to, and the only route in is to stop minding whether it comes, which cannot be done on purpose either.

This engine is defined by its [manifest](package.json), which the canon renders as the WIRES card. The manifest is the single source of truth; this README is generated, not edited by hand.
