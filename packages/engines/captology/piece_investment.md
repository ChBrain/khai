# Piece: Investment

## Taxonomy

[Captology](piece_captology.md), the facet this is a part of. Investment models what the user puts in that deepens the hook and improves the next turn -- the data, the effort, the followers, the streak, the stored history that makes the object worth more to them and harder to leave. Eyal's investment phase: the user's own input loads the next trigger and raises the cost of quitting. It is distinct from the other three, which drive a single loop; investment is the ratchet across loops, the reason each turn binds a little tighter than the last.

## Owner

- Project: khai
- Engine: captology

## Place

At every point the object asks the user to add something -- the profile filled, the content posted, the connection made, the streak kept -- and in the accumulated store of everything they have put in.

## Load Bearing

What investment holds up is the rising cost of leaving. The more the user has put in -- the years of history, the network, the reputation, the unbroken streak -- the more leaving forfeits, so they stay for what they would lose. Remove the investment -- let the user carry their value out, or store none of it in the object -- and leaving costs nothing but the habit; the retention rests on the sunk and the stored. Investment turns use into a stake, and the stake into a cage the user built for themselves.

## Apparent

What shows is personalization, ownership, a thing made theirs; what is built is a hostage the user themselves supplied. Each contribution looks like value gained, and it is -- value that is now held inside the object and cannot easily be carried out again.

## Yearbook

The history of an investment is the record of what the user built inside the object and could not take with them -- the archives, the followings, the streaks defended for their own sake long after the joy had gone. The object is dated from the stakes it accrued against the user's freedom to leave.
