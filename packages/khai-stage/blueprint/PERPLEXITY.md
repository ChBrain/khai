# PERPLEXITY.md, the {{SOURCE_TITLE}} house

Perplexity-specific notes for this house.

None are recorded yet, and the file is here anyway: it is the one address a
Perplexity quirk has, so one can never land in another tool's file. An empty
vendor file is an address, not an oversight.

**Do not assume it is discovered automatically.** No Perplexity convention documents
a file of this name, so it is reached because `README.md` links it or because
someone opened it in the request. Treat it as supplementary, and never as a
contract: everything that governs work here is in `AGENTS.md`, and where the two
appear to disagree, that one wins and this one is wrong.

Note also that a quirk of _working the repository_ is not a quirk of a Perplexity
Space receiving a finished production. The second kind lives in that Venue's
adaption, in `khai-engine-spine`, and the two must not be merged.
