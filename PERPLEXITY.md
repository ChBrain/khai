# PERPLEXITY.md — khai monorepo

Perplexity-specific notes for this repository.

None are recorded yet, and the file is here anyway: it is the one address a
Perplexity quirk has, so one can never land in another tool's file.

**Do not assume it is discovered automatically.** No Perplexity convention
documents a file of this name, so it is reached because `README.md` links it or
because someone opened it in the request. Treat it as supplementary and never as
a contract.

A quirk of _working this repository_ is not a quirk of a Perplexity deployment
receiving a finished production. The second kind lives in that Venue's adaption,
in `packages/engines/spine/`, and the two must not be merged.
