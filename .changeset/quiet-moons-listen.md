Ship the conduct doctrine: `architecture/conduct.md`, the shared case law for a
model working in any khai house.

Every repo using khai is a house of khai, and each keeps three layers: its own
voice layer (`management/`), its own `CLAUDE.md` (the short executable contract
of lanes, gates and quirks), and the case law those contracts point at. The
third had no home, so each house re-derived it. This is that home, and it ships
with the canon so it reaches every house by dependency.

Merged from two documents, both August 2026: a working session in this repo and
the khai-cultures house's "Working with a second LLM". Where both houses reached
the same law independently, the law leads with both cases under it.

Also corrects `architecture/_schema.yml`'s description, which named a count of
typed spec files that had gone stale and named one companion file where there
were already two.
