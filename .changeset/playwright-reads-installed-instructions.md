The Playwright reads what the installed packages say about themselves.

Mode B now opens by running `khai-tests instructions --law`, which collects the
`playwright_instructions.md` of every khai content package the repository
DECLARES, dependencies first. 376 packages ship one and the Playwright never saw
them: the guidance a package wrote about its own wiring reached the author only
if a model happened to open the file.

It is the repository's own tree, never a global list, so a cultures house gets
the language engine and its tongues and another house gets its own packages. The
skill says to take chapters package by package rather than with `--full`, for the
reason the collector has two layers at all: five chapters times a large
dependency tree is most of a context window spent on packages the play never
touches.

Requires the collector, which ships in khai-tests.
